# LEO — Website UI Kit

Marketing site components + a sample landing page.

## Files
- `index.html` — full landing page (hero, features, stats, code, footer)
- `components/Nav.jsx`
- `components/Hero.jsx`
- `components/FeatureGrid.jsx`
- `components/CodeShowcase.jsx`
- `components/StatsBand.jsx`
- `components/CTA.jsx`
- `components/Footer.jsx`

## Usage

Open `index.html` directly. All components are loaded via Babel-standalone in-browser; no build step.
